# AromaMuse

Адаптивная витрина парфюмерного бутика. Откройте `index.html` в браузере или запустите локальный сервер: `python3 -m http.server 8000`.

Данные каталога находятся в `script.js`. Названия, цены, описания и отзывы приведены как демонстрационные и требуют проверки владельцем. Изображения являются иллюстрациями и не изображают фирменную упаковку товаров.

Кнопки мессенджеров открывают форму, но отправка заявки пока не подключена: для этого нужны реальные адреса аккаунтов магазина. Укажите их и настройте обработчик формы в `script.js` перед публикацией.
