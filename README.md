# AromaMuse

Адаптивная витрина парфюмерного бутика. Запуск: `python3 -m http.server 8000`, затем откройте http://localhost:8000.

## Выбор и заявка

Покупатель отмечает ароматы сердечками. Сердечко в шапке и мобильной панели открывает избранное, где можно выбрать объёмы, удалить позиции и подготовить общую заявку в Telegram или WhatsApp. Избранное и объёмы сохраняются локально. Корзины и отдельного оформления покупки нет.

`script.js` содержит базовый каталог; `shop.js` — подробные карточки, фильтры и заявки из избранного.

Перед публикацией:
- В объекте `shop` задайте `telegram` (имя аккаунта без @) и `whatsapp` (международный номер).
- Замените демонстрационные `variants` точными ценами каждого объёма. Сейчас цены рассчитываются пропорционально базовой цене исключительно для демонстрации.
- Укажите `available` для товаров: `true`, `false` или `null` (уточнить).
- После проверки цен отключите `shop.demo`. Само отключение флага не меняет цены.
- Замените иллюстрации фотографиями, добавьте подтверждённые условия доставки/оплаты, происхождение товара и отзывы.

Без контактов мессенджеров сайт показывает пояснение и позволяет скопировать заявку. При настроенных контактах открывается черновик, который покупатель отправляет самостоятельно. Текст заявки содержит ароматы и объёмы; цену и наличие подтверждает магазин.

Проверено в Chromium: добавление сердечком, заявка из нескольких ароматов, изменение и сохранение объёмов, сохранение избранного, удаление и пустой список, выбор через подробную карточку, отсутствие элементов корзины, мобильная навигация и отсутствие горизонтального переполнения на ширине 390 px.
