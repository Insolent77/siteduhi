# AromaMuse

Адаптивная витрина парфюмерного бутика. Откройте `index.html` в браузере или запустите локальный сервер: `python3 -m http.server 8000`.

Данные каталога находятся в `script.js`. Названия, цены, описания и отзывы приведены как демонстрационные и требуют проверки владельцем. Изображения являются иллюстрациями и не изображают фирменную упаковку товаров.

Кнопки мессенджеров открывают форму, но отправка заявки пока не подключена: для этого нужны реальные адреса аккаунтов магазина. Укажите их и настройте обработчик формы в `script.js` перед публикацией.

## Каталог и оформление

`shop.js` добавляет карточку аромата, совместные фильтры, сохраняемую корзину, подготовку заказа для Telegram/WhatsApp и мобильную панель.

Перед публикацией:
- В `shop` задайте `telegram` (имя аккаунта без @) и `whatsapp` (международный номер).
- Замените демонстрационные `variants` точными ценами каждого объёма. Сейчас цены рассчитываются пропорционально базовой цене исключительно для демонстрации.
- Укажите `available` для товаров: `true`, `false` или `null` (уточнить).
- После проверки цен отключите `shop.demo`. Само отключение флага не меняет цены.
- Замените иллюстрации фотографиями, добавьте подтверждённые условия доставки/оплаты, происхождение товара и отзывы. Ноты сейчас перечислены без неподтверждённого разделения на пирамиду.

Без контактов отправка заказа не открывает стороннего получателя: покупатель видит пояснение и может скопировать заказ. Подключённый мессенджер открывает черновик; сообщение отправляет сам покупатель.

Проверено в Chromium: добавление и изменение количества, сохранение корзины, фильтры, подробная карточка, выбор объёма, обработка отсутствующих контактов, мобильная навигация и отсутствие горизонтального переполнения на ширине 390 px.
